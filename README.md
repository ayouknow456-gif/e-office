# E-OFFICE Full Workflow v2.0
ระบบสำนักงานอิเล็กทรอนิกส์ต้นแบบ ใช้ GitHub Pages + Google Apps Script + Google Sheets เท่านั้น ไม่มี Google Drive

## โครงสร้าง
- `index.html` หน้าเว็บ
- `assets/css/` รูปแบบหน้าจอ
- `assets/js/` ตัวแก้ไขเอกสาร ตัวเชื่อม GAS และโมดูลบริหารสำนักงาน
- `gas/Code.gs` Backend API
- `GAS-SETUP.md` คู่มือติดตั้งและอัปเกรด

## โมดูล
จัดทำเอกสาร, ทะเบียนหนังสือรับ/ส่ง, งานมอบหมาย, เสนอและอนุมัติ, ทะเบียนผู้ใช้งาน, แจ้งเตือน, ตั้งค่าระบบ, Audit Log, ออกเลขลำดับ, ส่งออก CSV

## เริ่มต้น
อ่าน `GAS-SETUP.md` ก่อนติดตั้ง แล้วเชื่อม URL `/exec` ในหน้า Settings

**สถานะ:** รุ่นพัฒนาต่อยอด/ต้นแบบ ไม่ใช่ระบบสารบรรณที่ผ่านการรับรองหรือระบบที่ปลอดภัยสำหรับเอกสารราชการจริง ต้องเพิ่ม authentication, authorization, audit integrity, backup และทดสอบระเบียบ/แบบฟอร์มของหน่วยงานก่อนใช้งานจริง
